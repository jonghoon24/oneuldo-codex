# 오늘도 1차 버전 스펙

## 목표

매일의 습관 실천을 간편하게 기록하고, 연속 일수와 월별 달력으로 얼마나 꾸준히 이어 왔는지 확인할 수 있게 한다.

## 이번에 만드는 기능

### 습관 관리

- 이름만 입력해 습관을 등록한다.
- 이름은 앞뒤 공백 제거 후 1~20자이며 빈 값, 줄바꿈, 동일 이름을 허용하지 않는다.
- 모든 습관은 별도 요일 설정 없는 매일 습관이다.
- 새 습관은 등록순으로 목록 끝에 추가하며 자동으로 오늘 완료 처리하지 않는다.
- 이름 변경 시 시작일과 체크 기록은 유지한다.
- 삭제 시 기록도 영구 삭제된다는 확인을 받은 후 제거한다.
- 직접 재정렬 기능은 제공하지 않는다.

### 습관 선택과 오늘 체크

- 습관 목록에서 하나를 선택하면 해당 습관의 연속 일수와 달력을 표시한다.
- 목록과 달력 양쪽에서 오늘 완료 여부를 토글할 수 있으며 두 화면은 즉시 동기화된다.
- 새 습관을 만들면 해당 습관을 선택한다.
- 재접속 시 마지막 선택을 복원하지 않고 등록순 첫 습관을 선택한다.
- 선택된 습관 삭제 후에는 다음 습관을 선택하고, 다음 습관이 없으면 이전 습관을 선택한다.

### 달력과 기록

- 달력은 월요일부터 시작하며 처음에는 현재 달을 표시한다.
- 오늘과 지난 날짜는 자유롭게 체크하거나 해제할 수 있다.
- 미래 날짜는 비활성화한다.
- 과거 기록을 수정하면 연속 일수를 즉시 다시 계산한다.

### 연속 일수

- 최고 기록이나 누적 통계가 아닌 현재 연속 기록만 표시한다.
- 오늘이 체크되어 있으면 오늘부터 과거 방향으로 연속된 일수를 계산한다.
- 오늘이 아직 체크되지 않았지만 어제가 체크되어 있으면 어제까지의 연속 기록을 유지한다.
- 어제도 체크되지 않았다면 현재 연속 일수는 0일이다.
- 체크 기록이 전혀 없어도 0일로 표시한다.

### 날짜와 저장

- 브라우저의 현재 현지 날짜를 '오늘'로 사용한다.
- 기록 날짜는 시간대 없는 현지 달력 날짜(`YYYY-MM-DD`)로 저장하므로 시간대가 바뀌어도 기존 날짜를 이동시키지 않는다.
- 자정을 넘기거나 탭이 다시 활성화되면 오늘, 달력, 연속 일수를 갱신한다.
- 브라우저 저장 데이터에 데이터 형식 버전, 습관 ID, 이름, 등록일, 완료 날짜 목록과 등록 순서를 보관한다.
- 새로고침하거나 브라우저를 다시 열어도 기록을 복원한다.
- 저장소 접근, 데이터 파싱 또는 쓰기에 실패하면 한국어 오류를 표시하고 변경 기능을 막는다.
- 손상된 데이터를 빈 데이터로 덮어쓰지 않으며, 쓰기에 실패한 화면 변경은 되돌린다.
- 데이터가 현재 브라우저에만 저장되고 브라우저 데이터 삭제 시 복구할 수 없음을 화면에 안내한다.

### 화면 상태

- 사용자 인터페이스는 React로 구현한다.
- 습관이 없을 때 기능 설명과 첫 습관 등록 행동을 제공한다.
- 모바일에서는 목록과 상세를 세로로, 넓은 화면에서는 나란히 배치한다.
- 모든 버튼, 오류, 확인창, 빈 상태와 날짜 관련 문구를 한국어로 제공한다.

## 안 하는 것

- 알림과 리마인더
- 로그인, 사용자 계정과 서버 저장
- 여러 기기 또는 브라우저 간 동기화
- 통계 전용 화면, 최고 연속 기록, 차트와 분석
- 요일별, 주 N회 또는 횟수형 습관
- 태그, 카테고리, 색상과 아이콘 꾸미기
- 습관 직접 재정렬과 보관함
- 데이터 내보내기, 가져오기와 삭제 데이터 복구
- 한국어 이외의 다국어 지원
- 스크린 리더 대응, 키보드 전용 조작 같은 접근성 대응

## 완료 조건

- AC-1: 앞뒤에 공백이 있는 유효한 이름으로 습관을 등록하면 공백이 제거된 이름으로 등록순 목록 끝에 추가되고 그 습관이 선택된다. 등록 직후에는 오늘이 미완료이고 연속 일수는 0일로 표시된다.
- AC-2: 공백뿐인 이름, 앞뒤 공백 제거 후 20자 초과인 이름, 줄바꿈이 포함된 이름 또는 기존 습관과 같은 이름으로 등록하거나 이름을 변경하면 저장되지 않고 한국어 오류가 표시된다. 앞뒤 공백 제거 후 1~20자인 중복 없는 이름은 저장된다.
- AC-3: 여러 습관이 있는 상태에서 목록의 다른 습관을 선택하면 상세에 선택한 습관의 기록과 연속 일수가 표시된다. 완료 기록이 있는 습관의 이름을 유효한 다른 이름으로 변경하면 새 이름이 표시되고 시작일과 완료 기록은 그대로 유지된다.
- AC-4: 목록에서 오늘을 체크하면 달력에도 즉시 완료로 표시되고, 달력에서 오늘 체크를 해제하면 목록에서도 즉시 미완료로 표시된다. 등록일 이전을 포함한 지난 날짜도 체크하거나 해제할 수 있으며, 변경한 기록과 연속 일수가 즉시 반영된다.
- AC-5: 완료 기록이 없는 습관을 선택하면 연속 일수는 0일로 표시된다. 그 상태에서 그저께, 어제, 오늘을 체크하면 3일이 표시되고, 오늘만 해제하면 어제까지의 2일이 유지되며, 어제도 해제하면 0일이 된다.
- AC-6: 다른 완료 기록이 없고 오늘이 2월 1일인 상태에서 1월 31일과 2월 1일을 체크하면 연속 일수는 2일이다. 오늘이 1월 1일일 때 전년도 12월 31일과 오늘을 체크해도 2일이다. 오늘까지 3일 연속 체크된 상태에서 가운데 날짜를 해제하면 연속 일수는 1일로 바뀐다.
- AC-7: 앱을 열면 달력은 현지 날짜의 현재 달을 월요일 시작으로 표시한다. 미래 날짜를 체크하려 해도 비활성화되어 기록이 바뀌지 않고, 현재 달에서 다음 달로 이동하려 해도 이동할 수 없다. 완료 기록이 없는 달로 이동하면 그 달에는 완료 표시가 없다.
- AC-8: 선택한 습관의 삭제를 취소하면 습관과 기록이 유지된다. 삭제를 확인하면 습관과 기록이 제거되고 등록순 다음 습관이 선택되며, 다음 습관이 없으면 이전 습관이 선택된다. 마지막 습관을 삭제하면 기능 설명과 첫 습관 등록 행동이 표시된다.
- AC-9: 등록, 이름 변경, 완료 기록 수정 또는 삭제에 성공한 뒤 새로고침하거나 브라우저를 다시 열면 변경된 습관과 기록이 유지된다. 여러 습관이 있으면 마지막 선택과 관계없이 등록순 첫 습관이 선택된다.
- AC-10: 오늘만 체크된 습관을 선택한 채 앱을 다음 날 자정까지 열어 두거나 다음 날 탭을 다시 활성화하면, 오늘 표시가 새 날짜로 옮겨지고 새 오늘은 미완료이며 연속 일수는 1일로 유지된다. 월이 바뀌었다면 달력에서 새 현재 달까지 이동할 수 있다. 기기 시간대를 바꾼 뒤 앱을 다시 열어도 기존 완료 기록의 달력 날짜는 이동하지 않는다.
- AC-11: 저장소에 접근할 수 없거나 저장 데이터가 손상된 상태에서 앱을 열면 한국어 오류가 표시되고 변경 기능이 차단되며 기존 저장 내용이 덮어써지지 않는다. 습관 등록, 이름 변경, 체크 변경 또는 삭제를 저장하는 중 쓰기에 실패하면 화면은 변경 전 상태로 돌아가고 한국어 오류가 표시되며 이후 변경이 차단되고 기존 저장 기록은 유지된다.
- AC-12: 습관이 없는 상태에서 앱을 열면 기능 설명과 첫 습관 등록 행동이 표시된다. 모바일 화면에서 앱을 열면 목록과 상세가 세로로, 넓은 화면에서 열면 나란히 표시되고 달력과 주요 조작이 잘리지 않는다. 앱을 열거나 등록·삭제·입력 오류 상황을 거치면 버튼, 오류, 확인창, 빈 상태와 날짜 문구가 한국어로 표시되며, 기록이 현재 브라우저에만 저장되고 브라우저 데이터 삭제 시 복구할 수 없다는 안내가 보인다.
- AC-13: 습관을 등록하거나 이름 변경, 체크 변경, 삭제, 기록 조회를 하면 그 동작을 위해 외부 서버로 네트워크 요청을 보내지 않는다.
